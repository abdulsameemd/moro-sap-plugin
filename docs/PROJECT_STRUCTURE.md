## What runs as ADK hooks (deterministic — not AI)

```
.claude/settings.json              ← wires all hooks into Claude Code

PreToolUse  → pre-lint-gate.js     ← fires before Write/Edit — lint must pass
PostToolUse → post-atc-check.js    ← fires after writeObjectSource — ATC must pass
SessionStart→ session-start-handoff.js ← fires once on session open — loads handoff
Stop        → stop-confirm-review.js   ← fires at end of response — CONFIRM REVIEW required
Stop        → stop-approve-transport.js← fires at end of response — APPROVE TRANSPORT required
```

**Event types — when no matcher is needed:**
- `SessionStart` and `Stop` fire unconditionally — no tool matcher required
- `PreToolUse` and `PostToolUse` need a matcher to specify which tool to intercept
